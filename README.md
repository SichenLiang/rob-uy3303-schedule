# ROB-UY 3303 — Course Schedule (unofficial calendar mirror)

An iCalendar (`.ics`) mirror of the lecture and assignment schedule published on
the public ROB-UY 3303 course site.

## Subscribe

```
webcal://sichenliang.com/rob-uy3303-schedule/schedule.ics
```

Opening that link on iOS or macOS brings up the subscription dialog directly.
Any calendar client that takes a URL works too — use the `https://` form:

```
https://sichenliang.com/rob-uy3303-schedule/schedule.ics
```

Subscribe, don't download-and-import: a subscription picks up later changes,
an import is a one-time snapshot that will go stale.

## What's in it

Lectures as all-day events, and assignments as timed events anchored to
`America/New_York`, each with a one-day-ahead alarm. Every event carries a link
back to the page it came from, plus the source line it was parsed out of, so a
questionable entry can be traced to its origin.

## Source

Scraped from the two public pages of the course site:

- <https://sites.google.com/nyu.edu/rob-uy3303/lectures>
- <https://sites.google.com/nyu.edu/rob-uy3303/assignments>

Nothing else feeds this file. No login-gated system is read, and no personal
data of any kind is collected, stored, or published here.

## Updates

Regenerated and pushed by hand, typically once a week and whenever the course
site is known to have changed. The file is only rewritten when the schedule
itself actually changes. `DTSTAMP` in the file records when it was last built.

There is no automation behind this repository — if the course site changes and
nobody runs the update, this file silently stays stale. Which is the main reason
for the disclaimer below.

## Disclaimer

**This is an unofficial, personal mirror, not a course deliverable and not
affiliated with or endorsed by the instructor, the department, or NYU.** It is
generated by scraping a public web page, so it can be wrong: parsing can drop or
misread an entry, and the mirror can lag behind the site. **The official course
site is authoritative.** Check it before relying on any date here — especially
for anything graded.

Provided as-is, with no warranty of accuracy or availability.
